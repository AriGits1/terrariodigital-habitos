CÓMO IMPORTAR A FIGMA:
1. Descomprime esta carpeta
2. Abre Figma → File → Import (o arrastra los SVGs al canvas)
3. Cada SVG se importa como un frame independiente y editable
4. Selecciona todos los frames → desagrupalos con Ctrl+Shift+G
5. Conéctalos con las flechas de prototipo en la pestaña "Prototype"
6. Usa "Present" (▶) para la presentación interactiva
